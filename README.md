# Сайт-візитівка та дослідження економічної безпеки Латвії

## Файли проєкту
- `index.html` — сторінка **«Про автора»** (без фото).
- `latvia.html` — сторінка **«Економічна безпека Латвії»**: опис, ключові показники, графіки з поясненнями, таблиця, сильні сторони й вразливості, загрози, напрями зміцнення, висновок і джерела.
- `styles.css` — стилі та адаптивність.
- `script.js` — дані, таблиця та графіки.

## Як відкрити локально
Розпакуйте ZIP та відкрийте `index.html` у браузері. Для графіків потрібне інтернет-з'єднання (Chart.js завантажується з CDN).

## Публікація через GitHub Pages
1. Увійдіть у GitHub або створіть акаунт.
2. Створіть новий репозиторій (наприклад, `latvia-economic-security`).
3. Завантажте **вміст** цієї папки в репозиторій: `index.html`, `latvia.html`, `styles.css`, `script.js`, `README.md`.
4. Натисніть **Commit changes**.
5. У репозиторії відкрийте **Settings → Pages**.
6. У **Build and deployment** виберіть **Deploy from a branch**.
7. Branch: `main`; Folder: `/ (root)`; натисніть **Save**.
8. Через кілька хвилин GitHub Pages покаже посилання на опублікований сайт. Відкрийте його й перевірте обидві сторінки та графіки.

## Примітка щодо даних
Історичні статистичні ряди у графіках округлені для навчального огляду та мають бути остаточно звірені з офіційними базами World Bank, Eurostat і Центрального статистичного бюро Латвії. Дані 2025 року можуть бути попередніми або оновлюватися. Джерела та посилання розміщені на аналітичній сторінці.


## Дані та методологія

Графіки побудовано на фактичних рядах із наданих таблиць Excel: макроекономічна, виробнича, демографічна, енергетична, зовнішньоекономічна, інвестиційно-інноваційна, продовольча та соціальна складові. Періоди відрізняються залежно від наявності даних у вихідних таблицях. Фінансова складова описана за підсумковим звітом: борг центрального уряду оцінено як оптимальний, міжнародні резерви — як небезпечний індикатор. Окремого Excel-файлу з фінансовими часовими рядами серед доступних матеріалів не було, тому числові значення для неї не вигадувалися.

Для оновлення статистики користуйтеся першоджерелами, наведеними на сторінці дослідження (World Bank, Eurostat, Центральне статистичне бюро Латвії, МВФ, FAOSTAT та IEA).
